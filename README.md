# FileCounter
A program for counting files in a folder, displaying statistics in a table, sorting, and writing notes in the table. Tables are saved as a *.csv file. 
It is possible to edit saved files and sort them by comments. 
The program is written in Java 25. If JRE 25 is installed on the system, you can use FileCounter.jar to run the program.
To use the program under Windows OS without JRE installed, download ( https://cutt.ly/dt7V4mAi ) and install the FileCounterSetup.exe installer.
Project website: https://sites.google.com/view/autester
